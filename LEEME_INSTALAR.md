# DevIAs Panel\n1. Instala Python 3.10 o superior (python.org).\n2. Haz doble clic en **instalar.bat**. Crea las carpetas, comprueba los paquetes y genera **iniciar_devpanel.bat** (y detener_devpanel.bat).\n   Para instalar también los paquetes que falten:  `instalar.bat --instalar-paquetes`   · acceso directo en el escritorio: `instalar.bat --acceso-directo`.\n3. Enciende el panel con **iniciar_devpanel.bat**: se abre http://localhost:8820/static/admin.html\n4. Pon un plugin en la carpeta `plugins/` y actívalo desde la pestaña Plugins.\n\nSi mueves la carpeta a otro lugar, vuelve a ejecutar instalar.bat para regenerar los .bat con las rutas nuevas.\nPara las voces ejecuta `python instalar_voces.py` (Piper y Kokoro, locales).\n Para elegir si te atiende Claude o Codex (y pasar de uno a otro) lee GUIA_AGENTES.md.
